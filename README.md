As part of Task 3 for the Future Interns Cybersecurity Internship, I performed a read-only API Security Risk Analysis on the ReqRes REST API platform (https://reqres.in), evaluating backend service endpoints against the OWASP API Security Top 10 (2023) framework. Using automated Python testing scripts, HTTP client inspection, and a pre-configured Postman collection, the assessment evaluated object-level authorization, authentication token hygiene, Cross-Origin Resource Sharing (CORS), and response data filtering. The audit identified five primary security risks, headlined by Broken Object Level Authorization (BOLA / IDOR) that allows unauthenticated callers to harvest customer records via sequential numerical IDs (/api/users/1, /api/users/2). Additional findings include weak static login tokens lacking cryptographic signatures or expiration, excessive data exposure in user JSON models, and an overly permissive wildcard CORS policy (Access-Control-Allow-Origin: *). The deliverable provides a comprehensive AppSec report detailing CVSS 3.1 ratings, business impacts, and a developer remediation roadmap.
