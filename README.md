As part of Task 1 for the Future Interns Cybersecurity Internship, I conducted an ethical, read-only vulnerability assessment on Altoro Mutual (testfire.net). Adhering strictly to passive reconnaissance guidelines and the OWASP Web Security Testing Guide (WSTG), the audit evaluated public-facing web infrastructure using custom Python socket scanning, cURL, and browser Developer Tools. The assessment uncovered ten security weaknesses across transport security, HTTP headers, session management, and server exposure. Key findings include cleartext HTTP transmission without forced HTTPS redirection, complete absence of protective browser headers (Content-Security-Policy, HSTS, X-Frame-Options), session cookies lacking Secure and SameSite flags, and unnecessary exposure of legacy mail service ports (25, 110, 143). The final audit report translates technical vulnerabilities into clear business impacts, outlines risk classifications (High, Medium, Low), and provides a phased engineering remediation roadmap to secure customer data and maintain compliance.
